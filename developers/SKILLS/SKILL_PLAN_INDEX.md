# SKILL_PLAN_INDEX

## 适用场景

- 新建计划文档
- 调整阶段状态或里程碑
- 完成验收与归档

## 输入

- 计划文档路径
- 计划状态变更（进行中/已完成/暂停/取消）
- 验收证据或里程碑依据

## 前置检查

1. 确认计划是否基于 `developers/PLANS/TEMPLATE.md`。
2. 确认上游总计划或索引是否引用该计划。
3. 确认状态变更是否有对应依据（测试结果、报告、评审结论）。

## 执行步骤

1. 使用 `developers/PLANS/TEMPLATE.md` 作为计划结构基线。
2. 明确计划状态（进行中、已完成、暂停、取消）并更新正文。
3. 检查 `developers/INDEX.md` 与相关总计划索引是否需同步。
4. 当计划完成时，补齐 DoD 与验收结论，标注证据来源。
5. 记录本次更新影响的上下游文档。

## 输出

- 计划状态更新摘要
- 已同步的索引与引用列表
- 待补充证据或阻断事项

## 失败处理

- 缺少验收证据：状态不得标记为已完成，改为进行中并注明阻断原因。
- 索引冲突：以当前权威索引为准，记录冲突项并给出修复建议。
- 多文档状态不一致：先修正文档状态，再修复索引引用。

## 示例

- 输入："将 Phase 10 标记为已完成并同步总计划"
- 执行：更新阶段文档状态与 DoD，补验收证据，更新总计划索引状态。
- 输出：列出状态变更、同步位置与遗留风险。

## 完成标准

- 计划状态与正文内容一致。
- 入口索引与引用链路完整。
- 验收结论具备可追溯依据。
